전문 분야

CAD 도면 자동화부터 BIM 데이터 추출, 그리고 그 데이터로 물량을 뽑는 적산까지. 세 레이어가 겹치는 지점에서 일합니다.

색상레이어내용
A-CAD-API

AutoCAD·BricsCAD .NET API(C#)로 플러그인을 개발합니다. 명령어, 리본 UI, 블록·XData·Overrule, 도면 일괄 처리와 설치본 배포까지 전 과정을 다룹니다.

AutoCAD .NETBricsCADObjectARXAutoLISPBundle 배포
A-BIM-REVIT

Revit API로 BIM 모델링과 정보 추출을 자동화합니다. 패밀리·파라미터 관리, 요소 생성, 일정표, 링크 모델 처리, 2023~2026 버전별 API 차이 대응.

Revit APIIExternalCommandFilteredElementCollectorRibbon.addin
A-QTY-적산

도면과 모델에서 물량을 자동으로 산출합니다. 콘크리트·거푸집·철근 수량, 부재별 집계, 엑셀 보고서 생성까지 적산 실무에 맞춘 알고리즘을 만듭니다.
