도면 관리와 Google Drive 연결에서 처리하는 정보를 안내합니다.

정책 작성일: 2026년 10월 4일 · 운영자: 정준회

1. 처리하는 정보와 목적

  • 사용자 ID, 이름, 부서: 이용자 식별, 등록자 표시 및 도면 수정 권한 확인에 사용합니다.
  • DWG 도면, PNG 미리보기, 파일명, 파일 크기, 프로젝트, 키워드, 설명, 등록 시각: 도면 보관·검색·조회·다운로드에 사용합니다. 파일 내용에 개인정보가 포함되면 해당 정보도 파일과 함께 저장됩니다.
  • Google Drive 파일 식별자와 OAuth 인증 토큰: 운영자가 승인한 Google Drive에 파일을 저장하고 불러오는 데 사용합니다.
  • 인증 정보 및 접속·오류 기록: 사용자와 관리자 인증, 서비스 운영 및 장애 확인에 사용합니다.

2. Google 계정 및 데이터 접근

운영자는 Google 동의 화면에서 Drive 연결을 승인합니다. DWG Manager는 https://www.googleapis.com/auth/drive.file 권한으로 앱이 생성하거나 사용 권한을 부여받은 파일을 처리합니다. 전체 Drive 파일을 읽는 권한이나 Gmail·연락처 접근 권한은 요청하지 않습니다.

Google에서 받은 데이터는 도면 및 미리보기의 저장, 조회, 다운로드와 그 기능 운영에만 사용합니다. 광고, 판매 또는 범용 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용 및 다른 앱으로의 전송에는 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

3. 저장과 접근 범위

도면과 미리보기는 운영자가 연결한 Google Drive에, 사용자 정보와 도면 메타데이터는 운영 서버의 데이터베이스에 저장합니다. Google 인증 토큰은 서버에서 연결 유지에 사용합니다. 다운로드한 파일과 로컬 미리보기는 이용자의 PC에도 저장됩니다.

등록된 도면과 등록 정보는 해당 DWG Manager 시스템에 접근 권한이 있는 이용자가 조회·다운로드할 수 있습니다. 운영 관리자는 서비스 운영과 지원에 필요한 데이터에 접근할 수 있습니다. 파일 등록만으로 Google Drive의 인터넷 공개 링크를 생성하지는 않습니다.

파일 저장과 전송에는 Google Drive 서비스를 이용합니다. 이 소개 웹사이트는 GitHub Pages에서 제공되므로 방문 시 호스팅 제공자가 접속 정보를 처리할 수 있습니다. 이 웹사이트에는 별도의 광고 또는 방문 분석 스크립트를 설치하지 않습니다.

4. 보관과 삭제 요청

등록한 도면과 사용자 정보는 도면 관리 서비스를 제공하는 동안 보관하며, 현재 자동 보관 만료 기능은 없습니다. 정보 열람·정정·삭제 또는 이용 중단은 아래 연락처로 요청할 수 있습니다. 운영자는 요청자의 권한을 확인한 뒤 처리 범위와 결과를 안내합니다. 백업이나 다른 이용자가 이미 내려받은 사본은 별도 확인이 필요합니다.

5. Google 연결 해제

연결한 Google 계정의 타사 앱 및 서비스 연결 관리에서 DWG Manager의 접근 권한을 철회할 수 있습니다. 철회하면 Drive 연결 기능이 중단될 수 있습니다. 권한 철회만으로 이미 저장한 도면, 서버 정보 또는 다운로드한 사본이 자동 삭제되지는 않으므로 삭제가 필요하면 운영자에게 요청해 주세요.
